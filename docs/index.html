Poradnik po odcinku

Twój Codex w appce. Bez klucza API.

Agent Codexa wbudowany we własną aplikację przez Codex SDK, zalogowany Twoim kontem ChatGPT. Appka to radar konkurencji YouTube na Twoim VPS: czyta nowe filmy i komentarze z kanałów konkurencji i układa raport - o co pytają widzowie, na co narzekają, czego jeszcze nikt nie nagrał.

Zero programowania. Plan robi agent, kod pisze agent, Ty podajesz dane i klikasz logowania. Chcesz zbudować coś innego niż radar? Podmieniasz jeden akapit i jedziesz tą samą drogą.

⏱ ok. 2 godziny z agentem 🧑‍💻 zero programowania 7 kroków 🔑 bez klucza API
Nie chcesz czytać? Otwórz Codex (albo Claude Code) w pustym folderze i wklej ten prompt. Agent poprowadzi Cię przez wszystkie kroki.

O CO CHODZI

Trzy rzeczy, zanim odpalisz agenta

1

API kontra subskrypcja

Z kluczem API płacisz za każdy token. Na subskrypcji ChatGPT masz limity (okno 5-godzinne i tygodniowe), a przy takiej appce zwykle wychodzi taniej. Ten poradnik jedzie na subskrypcji.

2

Agent SDK = gotowy agent do wpięcia w appkę

Nie piszesz własnego agenta. Codex SDK opakowuje silnik Codexa i pozwala go uruchamiać z własnego kodu: wątki z pamięcią, odpowiedź w zadanym schemacie JSON, sandbox z kontrolą sieci i katalogu, strumień zdarzeń z pracy agenta. I pozwala mu jechać na Twoim koncie ChatGPT.

3

Co buduje radar

Kanały konkurencji → RSS (nowe filmy) + yt-dlp (komentarze i transkrypcje z napisów) → raport w trzech kafelkach: pytania widzów, narzekania, luki tematyczne. Drugi przebieg pamięta pierwszy i oznacza pozycje „już zgłaszane”.

ZJEDZONE ZA CIEBIE

Pułapki, które wizard już zna

1Agent „nie może pobrać” RSS

Komenda kończy się błędem sieci, bo sandbox domyślnie nie ma internetu. Naprawa: networkAccessEnabled: true w opcjach wątku (albo new Codex({ config: { sandbox_workspace_write: { network_access: true } } })).

2Błąd „not a git repository”

Silnik wymaga repo git i odmawia pracy w data/. Naprawa: skipGitRepoCheck: true.

3yt-dlp: command not found w śladzie

Brak narzędzia w PATH procesu. Zainstaluj lokalnie; w Dockerze dodaj do obrazu (Krok 5).

4Tura trwa i trwa

Za dużo filmów i komentarzy. Limit 3 filmów i 100 komentarzy na kanał, bezpiecznik 10 minut na turę (AbortSignal.timeout(10 * 60_000)).

5finalResponse nie jest JSON-em

Schemat za luźny albo brak outputSchema. Naprawa: additionalProperties: false i wszystkie pola w required - tak jak w docs/schema.json.

6Panel pusty, 0 eventów

Użyty run() zamiast runStreamed(). Przełącz na runStreamed(), wtedy ślad kroków idzie na żywo.

7Connector udaje sukces przy aktualizacji
